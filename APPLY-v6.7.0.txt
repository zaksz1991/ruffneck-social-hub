RUFFNECK SOCIAL HUB v6.7.0 — ORGANISATION READINESS & PRESENTATION

BASELINE
This overlay targets public GitHub main at package version 6.6.0, reviewed on 5 November 2026. It adds an organisation-facing product overview, corrects misleading workspace dashboard placeholders, improves deployment documentation and adds free repository security automation. WHAT CHANGES
- Adds a public `/organizations` page that describes current capabilities and explicit provider limitations without exposing workspace data.
- Links the overview from the login page and explicitly allowlists `/organizations` in the global authentication middleware; private application routes remain protected.
- Reworks the signed-in dashboard to remove hard-coded conversation/AI zeroes and obsolete “in development” labels. Live numbers are shown only for the existing connected-account and queue-record queries; queue records are not represented as provider delivery.
- Preserves workspace creation, brand creation/rename, team access and existing route navigation.
- Replaces the repository README hotfix text with the real product overview.
- Documents the actual billing and cron environment variables in `.env.example`. Values remain blank; this does not set any secret.
- Adds `SECURITY.md`, CodeQL analysis and weekly Dependabot configuration. These use GitHub repository features; enable/monitor the applicable free public-repository security settings in GitHub.
- Adds capability helper tests and a pre-build organization-readiness audit.
- Adds no SQL migration, external runtime dependency, paid SaaS or new Vercel environment variable.

INSTALLATION
1. Extract this ZIP.
2. In GitHub, add the new files and replace each complete file at the exact path above.
3. Preserve any custom package.json scripts added since v6.6.0. The supplied package.json preserves the v6.6.0 scripts and adds only the v6.7.0 organization readiness test/audit hooks. No runtime dependency or Node engine restriction is added.
4. Commit to main and inspect the Vercel deployment.
5. Open `/organizations` publicly and `/` after signing in. Review both on desktop and mobile.
6. In GitHub → Security, enable and review the repository security features available for this public repo; review CodeQL alerts and Dependabot PRs instead of treating generated alerts as automatically fixed.

COST / SUBSCRIPTION
- No paid dependency or external SaaS is introduced by this overlay.
- The optional local AI endpoint avoids a required hosted-AI subscription but requires compute, maintenance and network access.
- Existing hosting, Supabase, Redis, provider APIs, WhatsApp, email, media scanning and storage remain subject to their own terms, quotas, usage limits and possible charges. Do not promise zero operating cost.

IMPORTANT ORGANISATION LIMITATIONS
- Provider API access and account scopes must be approved separately.
- TikTok public/scheduled publishing and YouTube public/scheduled publishing are not claimed.
- Facebook Page publishing must be verified against the actual enabled account path.
- AI does not auto-send public replies.
- No SOC 2, ISO 27001, NDPA/GDPR certification, formal SLA, independent penetration test or disaster recovery result is claimed.
- No committed package-lock.json was present on the inspected v6.6.0 public main baseline. A dependency lockfile remains a separate release-engineering requirement; do not fabricate one.
