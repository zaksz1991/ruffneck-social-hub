3. APPLY THE SUPABASE MIGRATION

In Supabase Dashboard:

- Open the RuffNeck project.
- Open SQL Editor.
- Confirm migrations 0043 and 0044 have already completed successfully.
- Open the ZIP file `supabase/migrations/0045_agency_client_management.sql`.
- Copy the entire SQL file into a new SQL Editor query.
- Run it once and confirm Supabase reports success.

Do not apply migration 0045 before migrations 0043 and 0044.

4. OPEN THE NEW CLIENT PORTFOLIO

Use the workspace ID already used by the application:

`/agency/clients?workspace=<workspace-id>`

The Plans & Billing page also contains a Manage agency clients link. Owners, admins and managers can use the portfolio. Other workspace roles are denied.

5. WHAT IS ENFORCED

- The plan's `max_client_workspaces` field is enforced against non-closed agency client records.
- Prospect, onboarding, active and paused records consume a slot.
- Closed records do not consume a slot.
- Reopening a closed record checks the allowance again.
- Database RPCs recheck the signed-in user's workspace role. Direct browser table writes are not granted.
- Notes are append-only through the protected RPC.

6. IMPORTANT SCOPE LIMITS

This release is an agency-side client directory. It does not invite clients into RuffNeck, share separate client workspaces, expose client social accounts, provide client post approvals or implement client billing. Do not describe these functions as available yet.
