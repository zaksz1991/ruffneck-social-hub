DATABASE

ENVIRONMENT

No new environment variable is required. The feature reuses the server-side settings already listed in .env.example:
- LOCAL_AI_BASE_URL
- LOCAL_AI_MODEL
- LOCAL_AI_API_KEY (optional)

Set LOCAL_AI_BASE_URL and LOCAL_AI_MODEL in the deployment server environment to enable the feature. Keep LOCAL_AI_API_KEY server-only. Do not create NEXT_PUBLIC_ versions of these variables.

For Vercel, the configured inference endpoint must be reachable from Vercel over HTTPS. A local computer's localhost address or private home/office LAN address is not reachable from Vercel's cloud runtime. The panel remains disabled until the server-side AI settings are present.

PERMISSIONS AND BEHAVIOUR

- AI analysis is available to workspace owner, admin, manager and analyst roles.
- The server action checks the authenticated user and workspace membership again. Hiding the button is not the security boundary.
- Manual and official provider metrics remain separate.
- The feature is read-only and does not publish, schedule, upload, send, launch ads or modify campaigns.
- No social platform permissions or provider integrations are changed.
