INSTALL THROUGH THE GITHUB WEBSITE
1. Open github.com/zaksz1991/ruffneck-social-hub and select the main branch.
2. Open README.md, choose Edit, replace its entire contents with this package's README.md, then commit.
3. Open .github/workflows/publishing-worker.yml, choose Edit, replace its entire contents with this package's workflow file, then commit.
4. In Vercel, open Project Settings → Environment Variables. Verify that SOCIAL_PUBLISH_CRON_SECRET exists for Production. It must be a strong value of at least 32 characters.
5. In GitHub, open Settings → Secrets and variables → Actions. Create or update the repository secret named SOCIAL_PUBLISH_CRON_SECRET with exactly the same value. Do not paste the secret into this chat, a source file, or a workflow log.
6. The workflow uses the fixed production endpoint https://ruffneck-social-hub.vercel.app/api/cron/publishing. RSH_WORKER_URL is not used by this replacement workflow.
7. After the Vercel deployment is ready, open Actions → RuffNeck scheduled publishing worker and use Run workflow once. Review the action result. A response with claimed=0 means the endpoint responded but no posts were due.
