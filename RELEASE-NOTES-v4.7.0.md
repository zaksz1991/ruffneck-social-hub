# Release Notes — v4.7.0

- WhatsApp conversations can be enrolled in Customer CRM.
- CRM supports internal labels, relationship stages, tags, recent message history and append-only private notes for WhatsApp.
- WhatsApp conversations now use the existing private AI triage adapter for intent, sentiment, summary, escalation recommendation and suggested priority.
- Priority application is a separate workspace-role-checked action and is bound to the exact latest inbound message.
- Existing Instagram/Facebook CRM and triage flows are preserved.
- WhatsApp SLA analytics, routing automation, reply playbooks and media send/download support remain future work.

Database: migration 0034 after migration 0033.
Environment: no new values.
