# v5.1.0 release notes

- Added workspace-scoped WhatsApp recipient consent state.
- Exact STOP-family inbound commands suppress outbound text, template and media sends.
- START and UNSTOP explicitly re-enable messaging.
- Added database-level enforcement on both outbound attempt ledgers.
- Added consent state visibility to the WhatsApp conversation view.
- Added regression tests and a production-build audit.
- No automatic customer acknowledgements or bulk messaging.
