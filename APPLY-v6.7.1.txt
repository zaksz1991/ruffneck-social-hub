RUFFNECK SOCIAL HUB v6.7.1 — INTERNAL IMPORT AUDIT HOTFIX

ROOT CAUSE
The v6.7.0 public organisation page imports `src/app/home.module.css` as a default CSS-module import. The internal-import audit correctly resolves the CSS path, but its default-import check incorrectly calls the TypeScript parser on the CSS file before reaching the asset-module guard. TypeScript then reports hundreds of false syntax errors from valid CSS.

GITHUB CHANGE
Replace the complete file:
- scripts/audit-internal-imports.mjs

Optional regression test included:
- scripts/test-internal-imports-assets.mjs

The replacement preserves source syntax checking, relative/alias path validation, and named-export validation for JavaScript/TypeScript modules. CSS, JSON and other non-code assets are still checked for path existence but are not parsed as TypeScript or treated as JavaScript named-export modules.
