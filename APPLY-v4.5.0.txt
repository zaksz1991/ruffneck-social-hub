FEATURE
Human-approved public replies to top-level Instagram comments. AI never sends replies automatically. One publish attempt is allowed for each reviewed draft. A timeout or ambiguous provider response is recorded as UNKNOWN and is not retried. Hide/unhide, delete, DMs and automatic comment replies are not included.

META / VERCEL CONFIGURATION
- Keep INSTAGRAM_ENABLE_COMMENT_MANAGEMENT=false until the Meta app has the correct permission access.
- To request the permission, set INSTAGRAM_ENABLE_COMMENT_MANAGEMENT=true in Vercel for Production (and Preview if required), then reconnect the Instagram professional account from Channels.
- The account must grant both instagram_business_basic and instagram_business_manage_comments. Existing connections do not gain new scopes automatically.
- Keep META_GRAPH_API_VERSION set to a supported Graph API version; if unset this code uses v26.0.
- Ensure SOCIAL_TOKEN_ENCRYPTION_KEY, NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY and SUPABASE_SERVICE_ROLE_KEY (or existing SUPABASE_SERVICE_KEY) are set as server environment variables.
- Never prefix the service-role key or token encryption key with NEXT_PUBLIC_. Never put them in browser code.
- Save environment variables and redeploy after changing them.

POST-DEPLOY CHECK
1. Use a test Instagram professional account and a test comment on media owned by that account.
2. Confirm the comment appears in /inbox/comments.
3. Generate a draft and mark it human-reviewed.
4. Confirm the publishing control is visible only when the feature flag, account connection and scopes are all valid.
5. Explicitly tick the consent checkbox and post once.
6. Confirm the reply appears publicly on Instagram and the attempt is marked SUCCEEDED.
7. Confirm a second submission is blocked.
8. Test an unavailable/expired token and verify no reply is sent.
9. Test a timeout/5xx condition only in a non-production environment. It must be marked UNKNOWN and must not offer automatic retry.
