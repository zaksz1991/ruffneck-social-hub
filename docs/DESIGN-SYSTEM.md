# RuffNeck Social Hub — Visual System

## Direction
Premium enterprise SaaS: deep navy navigation, light operational canvas, restrained cyan/teal accents, clear data hierarchy and compact information density. The system is designed for desktop operations and mobile access.

## Tokens
- Navy: `#101D35`
- Deep navy: `#172945`
- Canvas: `#F5F7FB`
- Surface: `#FFFFFF`
- Cyan: `#00B4D8`
- Teal: `#14B8A6`
- Main text: `#17243A`
- Muted text: `#748198`
- Border: `#E7EBF1`

## Assets
- `public/brand/ruffneck-logo.svg` — primary horizontal logo for light backgrounds.
- `public/brand/ruffneck-logo-inverse.svg` — inverse horizontal logo for dark backgrounds.
- `public/brand/ruffneck-symbol.svg` — standalone symbol.
- `public/favicon.svg` — browser favicon.
- `public/icons/` — navigation and product icon set, plus PNG app icons.
- `public/placeholders/` — neutral avatar, media and social-post preview placeholders.
- `public/flyers/` — editable vector flyer templates in portrait and square formats.

## Usage rules
- Use primary logo on light surfaces and inverse logo on dark surfaces.
- Keep the symbol's proportions; do not stretch or recolour it outside the palette.
- Use placeholders only when user-provided media is absent. Do not present placeholder graphics as real campaign performance or connected social accounts.
- Flyer SVGs are editable templates. Replace copy and imagery before publishing; do not imply the sample copy is a live offer or verified product feature.
- Maintain visible focus states, semantic labels and reduced-motion support.

## Accessibility
The interface uses semantic headings, form labels, keyboard focus rings, status text in addition to colour, and reduced-motion overrides. Contrast and full WCAG 2.2 AA conformance still require a formal audit before making a compliance claim.
